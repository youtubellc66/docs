`GET /v1/assets/all/prices/latest` returns the most recent NAV price for every supported tokenized real-world asset in a single request. This is the recommended endpoint for fetching price data because it minimizes API calls and counts as a single request against your rate limit.

## Endpoint

```
GET https://api.gm.ondo.finance/v1/assets/all/prices/latest
```

## Authentication

Requires a valid API key in the `Authorization` header:

```
Authorization: Bearer <your-api-key>
```

## Request example

<CodeGroup>
```bash cURL
curl https://api.gm.ondo.finance/v1/assets/all/prices/latest \
  -H "Authorization: Bearer $ONDO_API_KEY"
```

```javascript JavaScript
const response = await fetch(
  "https://api.gm.ondo.finance/v1/assets/all/prices/latest",
  {
    headers: { Authorization: `Bearer ${process.env.ONDO_API_KEY}` },
  }
);
const { data } = await response.json();
```

```python Python
import os, requests

response = requests.get(
    "https://api.gm.ondo.finance/v1/assets/all/prices/latest",
    headers={"Authorization": f"Bearer {os.environ['ONDO_API_KEY']}"},
)
prices = response.json()["data"]
```
</CodeGroup>

## Response fields

<ResponseField name="data" type="array">
  Array of price objects, one per active asset.

  <Expandable title="Price object fields">
    <ResponseField name="assetId" type="string">
      Unique asset identifier.
    </ResponseField>
    <ResponseField name="symbol" type="string">
      Token ticker symbol.
    </ResponseField>
    <ResponseField name="name" type="string">
      Full asset name.
    </ResponseField>
    <ResponseField name="price" type="string">
      Current NAV price per token as a decimal string. Parse with a decimal-aware library.
    </ResponseField>
    <ResponseField name="currency" type="string">
      Price denomination. Always `"USD"`.
    </ResponseField>
    <ResponseField name="timestamp" type="string">
      ISO 8601 UTC timestamp of when this price was published.
    </ResponseField>
    <ResponseField name="priceChange24h" type="string">
      Absolute price change over the last 24 hours as a decimal string.
    </ResponseField>
    <ResponseField name="priceChangePct24h" type="string">
      Percentage price change over the last 24 hours as a decimal string.
    </ResponseField>
  </Expandable>
</ResponseField>

## Error responses

| Status | Code | Description |
|---|---|---|
| `401` | `unauthorized` | API key is missing or malformed. |
| `403` | `forbidden` | API key does not have access. |
| `429` | `rate_limit_exceeded` | Rate limit exceeded. Check the `retryAfter` field. |
| `500` | `internal_error` | Server-side error. Retry with exponential backoff. |

<Note>
  Prices are updated once per US business day. The `timestamp` field indicates when the current price was last set. On weekends and US federal holidays, this timestamp will appear older than 24 hours — this is expected behavior.
</Note>
