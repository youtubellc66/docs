`GET /v1/assets/{assetId}` returns metadata for a single tokenized asset. Use this endpoint when you need detailed information about a specific asset identified by its `assetId`.

## Endpoint

```
GET https://api.gm.ondo.finance/v1/assets/{assetId}
```

## Authentication

Requires a valid API key in the `Authorization` header:

```
Authorization: Bearer <your-api-key>
```

## Path parameters

<ParamField path="assetId" type="string" required>
  The unique identifier of the asset (e.g., `ousg`, `ommf`, `usdy`). Asset IDs are case-sensitive and always lowercase. Use `GET /v1/assets` to retrieve the list of valid IDs.
</ParamField>

## Request example

<CodeGroup>
```bash cURL
curl https://api.gm.ondo.finance/v1/assets/ousg \
  -H "Authorization: Bearer $ONDO_API_KEY"
```

```javascript JavaScript
const assetId = "ousg";
const response = await fetch(
  `https://api.gm.ondo.finance/v1/assets/${assetId}`,
  {
    headers: { Authorization: `Bearer ${process.env.ONDO_API_KEY}` },
  }
);
const { data } = await response.json();
```

```python Python
import os, requests

asset_id = "ousg"
response = requests.get(
    f"https://api.gm.ondo.finance/v1/assets/{asset_id}",
    headers={"Authorization": f"Bearer {os.environ['ONDO_API_KEY']}"},
)
data = response.json()["data"]
```
</CodeGroup>

## Response

```json
{
  "data": {
    "assetId": "ousg",
    "symbol": "OUSG",
    "name": "Ondo Short-Term US Government Bond Fund",
    "description": "A tokenized fund investing in short-duration US Treasury securities.",
    "decimals": 18,
    "chainId": 1,
    "contractAddress": "0x1B19C19393e2d034D8Ff31ff34c81252FcBbee92",
    "currency": "USD",
    "isActive": true
  }
}
```

## Response fields

<ResponseField name="data" type="object">
  A single asset metadata object.

  <Expandable title="Asset object fields">
    <ResponseField name="assetId" type="string">
      Unique identifier for this asset.
    </ResponseField>
    <ResponseField name="symbol" type="string">
      Token ticker symbol.
    </ResponseField>
    <ResponseField name="name" type="string">
      Full human-readable name.
    </ResponseField>
    <ResponseField name="description" type="string">
      Description of the underlying fund.
    </ResponseField>
    <ResponseField name="decimals" type="integer">
      ERC-20 token decimal places.
    </ResponseField>
    <ResponseField name="chainId" type="integer">
      EVM chain ID of the token deployment.
    </ResponseField>
    <ResponseField name="contractAddress" type="string">
      On-chain ERC-20 contract address.
    </ResponseField>
    <ResponseField name="currency" type="string">
      Denomination currency. Always `"USD"`.
    </ResponseField>
    <ResponseField name="isActive" type="boolean">
      Whether the asset is currently active.
    </ResponseField>
  </Expandable>
</ResponseField>

## Error responses

| Status | Code | Description |
|---|---|---|
| `401` | `unauthorized` | API key is missing or malformed. |
| `403` | `forbidden` | API key does not have access. |
| `404` | `not_found` | No asset found with the given `assetId`. Verify the ID using `GET /v1/assets`. |
| `500` | `internal_error` | Server-side error. |
