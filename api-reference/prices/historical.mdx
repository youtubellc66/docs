`GET /v1/assets/{assetId}/prices/historical` returns a time-series of historical NAV prices for a specified asset, one data point per business day. Use this endpoint to build performance charts, calculate returns, or audit price history.

## Endpoint

```
GET https://api.gm.ondo.finance/v1/assets/{assetId}/prices/historical
```

## Authentication

Requires a valid API key in the `Authorization` header:

```
Authorization: Bearer <your-api-key>
```

## Path parameters

<ParamField path="assetId" type="string" required>
  The unique identifier of the asset (e.g., `ousg`, `ommf`, `usdy`).
</ParamField>

## Query parameters

<ParamField query="startDate" type="string">
  The start date for the historical range in `YYYY-MM-DD` format (UTC). If omitted, defaults to the asset's inception date.
</ParamField>

<ParamField query="endDate" type="string">
  The end date for the historical range in `YYYY-MM-DD` format (UTC). If omitted, defaults to the most recent available price date.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum number of data points to return. Defaults to `365`. Maximum is `1825` (approximately 5 years).
</ParamField>

<ParamField query="order" type="string">
  Sort order for results. Either `asc` (oldest first) or `desc` (newest first). Defaults to `asc`.
</ParamField>

## Request example

<CodeGroup>
```bash cURL
# Fetch 30 days of OUSG price history
curl "https://api.gm.ondo.finance/v1/assets/ousg/prices/historical?startDate=2024-01-01&endDate=2024-01-31" \
  -H "Authorization: Bearer $ONDO_API_KEY"
```

```javascript JavaScript
const assetId = "ousg";
const params = new URLSearchParams({
  startDate: "2024-01-01",
  endDate: "2024-01-31",
  order: "asc",
});

const response = await fetch(
  `https://api.gm.ondo.finance/v1/assets/${assetId}/prices/historical?${params}`,
  {
    headers: { Authorization: `Bearer ${process.env.ONDO_API_KEY}` },
  }
);
const { data } = await response.json();
```

```python Python
import os, requests

asset_id = "ousg"
params = {
    "startDate": "2024-01-01",
    "endDate": "2024-01-31",
    "order": "asc",
}
response = requests.get(
    f"https://api.gm.ondo.finance/v1/assets/{asset_id}/prices/historical",
    headers={"Authorization": f"Bearer {os.environ['ONDO_API_KEY']}"},
    params=params,
)
prices = response.json()["data"]
```
</CodeGroup>

## Response fields

<ResponseField name="data" type="array">
  Array of historical price points, ordered by `date`.

  <Expandable title="Price point fields">
    <ResponseField name="assetId" type="string">
      The asset identifier.
    </ResponseField>
    <ResponseField name="price" type="string">
      NAV price for this date as a decimal string.
    </ResponseField>
    <ResponseField name="currency" type="string">
      Denomination currency. Always `"USD"`.
    </ResponseField>
    <ResponseField name="date" type="string">
      The date for this price in `YYYY-MM-DD` format (UTC).
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  Metadata about the returned dataset.

  <Expandable title="Meta fields">
    <ResponseField name="assetId" type="string">
      The asset identifier for this dataset.
    </ResponseField>
    <ResponseField name="startDate" type="string">
      The actual start date of the returned data.
    </ResponseField>
    <ResponseField name="endDate" type="string">
      The actual end date of the returned data.
    </ResponseField>
    <ResponseField name="count" type="integer">
      Total number of price points returned.
    </ResponseField>
  </Expandable>
</ResponseField>

## Error responses

| Status | Code | Description |
|---|---|---|
| `400` | `bad_request` | Invalid date format or `startDate` is after `endDate`. |
| `401` | `unauthorized` | Missing or malformed API key. |
| `403` | `forbidden` | API key lacks permission. |
| `404` | `not_found` | Asset ID does not exist. |
| `429` | `rate_limit_exceeded` | Rate limit exceeded. |
| `500` | `internal_error` | Server error. Retry with backoff. |

<Note>
  Historical prices only include business days. Weekends and US federal holidays are excluded from the data series.
</Note>
