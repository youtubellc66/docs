The Ondo GM API provides two ways to retrieve asset prices: a bulk endpoint that returns all assets at once, and a per-asset endpoint for targeted queries. This guide shows you how to use both, parse the responses, and integrate price data into your application.

## Fetch all asset prices

The most efficient way to get price data is to call the bulk endpoint, which returns the latest price for every active asset in a single request:

```
GET /v1/assets/all/prices/latest
```

<CodeGroup>
```bash cURL
curl https://api.gm.ondo.finance/v1/assets/all/prices/latest \
  -H "Authorization: Bearer $ONDO_API_KEY"
```

```javascript JavaScript
const response = await fetch(
  "https://api.gm.ondo.finance/v1/assets/all/prices/latest",
  {
    headers: { Authorization: `Bearer ${process.env.ONDO_API_KEY}` },
  }
);
const { data } = await response.json();
```

```python Python
import os, requests

response = requests.get(
    "https://api.gm.ondo.finance/v1/assets/all/prices/latest",
    headers={"Authorization": f"Bearer {os.environ['ONDO_API_KEY']}"},
)
assets = response.json()["data"]
```
</CodeGroup>

## Fetch a single asset's price

When you only need the price for one specific asset, use the per-asset endpoint to reduce payload size:

```
GET /v1/assets/{assetId}/prices/latest
```

<CodeGroup>
```bash cURL
curl https://api.gm.ondo.finance/v1/assets/ousg/prices/latest \
  -H "Authorization: Bearer $ONDO_API_KEY"
```

```javascript JavaScript
const assetId = "ousg";
const response = await fetch(
  `https://api.gm.ondo.finance/v1/assets/${assetId}/prices/latest`,
  {
    headers: { Authorization: `Bearer ${process.env.ONDO_API_KEY}` },
  }
);
const { data } = await response.json();
console.log(`${data.symbol}: $${data.price}`);
```

```python Python
import os, requests
from decimal import Decimal

asset_id = "ousg"
response = requests.get(
    f"https://api.gm.ondo.finance/v1/assets/{asset_id}/prices/latest",
    headers={"Authorization": f"Bearer {os.environ['ONDO_API_KEY']}"},
)
data = response.json()["data"]
price = Decimal(data["price"])
print(f"{data['symbol']}: ${price}")
```
</CodeGroup>

## Parsing prices correctly

Asset prices are returned as decimal **strings** to preserve full precision. Always parse them using a decimal-aware type:

<CodeGroup>
```javascript JavaScript (BigNumber)
import { BigNumber } from "bignumber.js";

const price = new BigNumber(data.price);
const holdings = new BigNumber("1000"); // token balance
const valueUSD = price.multipliedBy(holdings);
console.log(`Portfolio value: $${valueUSD.toFixed(2)}`);
```

```python Python (Decimal)
from decimal import Decimal

price = Decimal(data["price"])
holdings = Decimal("1000")
value_usd = price * holdings
print(f"Portfolio value: ${value_usd:.2f}")
```
</CodeGroup>

<Warning>
  Do not use native JavaScript `Number` or Python `float` for financial calculations. These types lose precision for large decimal values and can introduce rounding errors.
</Warning>

## Checking price freshness

Use the `timestamp` field to verify that the price data is current before using it in calculations:

```javascript
const priceDate = new Date(data.timestamp);
const now = new Date();
const hoursSinceUpdate = (now - priceDate) / (1000 * 60 * 60);

if (hoursSinceUpdate > 28) {
  console.warn("Price data may be stale — markets may be closed");
}
```

<Note>
  Ondo GM prices are updated once per US business day. Prices will appear "stale" on weekends and US federal holidays — this is expected behavior, not an error.
</Note>
