This guide walks you through making your first authenticated request to the Ondo GM API. By the end, you will have retrieved live price data for all supported tokenized real-world assets.

## Prerequisites

Before you begin, you need:

- An active Ondo GM API key ([request access here](https://gm.ondo.finance))
- `curl`, Python, or Node.js installed on your machine

## Step 1: Set your API key

Store your API key as an environment variable so you do not need to paste it into every command:

<CodeGroup>
```bash macOS / Linux
export ONDO_API_KEY="your-api-key-here"
```

```powershell Windows (PowerShell)
$env:ONDO_API_KEY = "your-api-key-here"
```
</CodeGroup>

## Step 2: Fetch all asset prices

Call `GET /v1/assets/all/prices/latest` to retrieve the current prices for all supported RWA tokens:

<CodeGroup>
```bash cURL
curl https://api.gm.ondo.finance/v1/assets/all/prices/latest \
  -H "Authorization: Bearer $ONDO_API_KEY"
```

```javascript JavaScript (fetch)
const response = await fetch(
  "https://api.gm.ondo.finance/v1/assets/all/prices/latest",
  {
    headers: {
      Authorization: `Bearer ${process.env.ONDO_API_KEY}`,
    },
  }
);
const data = await response.json();
console.log(data);
```

```python Python
import os
import requests

api_key = os.environ["ONDO_API_KEY"]
headers = {"Authorization": f"Bearer {api_key}"}

response = requests.get(
    "https://api.gm.ondo.finance/v1/assets/all/prices/latest",
    headers=headers,
)
print(response.json())
```
</CodeGroup>

### Expected response

A successful request returns an HTTP `200` status and a JSON body containing an array of asset price objects:


## Step 3: Fetch a single asset

Once you know an asset's `assetId`, you can fetch its price individually:

<CodeGroup>
```bash cURL
curl https://api.gm.ondo.finance/v1/assets/ousg/prices/latest \
  -H "Authorization: Bearer $ONDO_API_KEY"
```

```javascript JavaScript
const assetId = "ousg";
const response = await fetch(
  `https://api.gm.ondo.finance/v1/assets/${assetId}/prices/latest`,
  {
    headers: {
      Authorization: `Bearer ${process.env.ONDO_API_KEY}`,
    },
  }
);
const data = await response.json();
```

```python Python
import os, requests

api_key = os.environ["ONDO_API_KEY"]
asset_id = "ousg"
response = requests.get(
    f"https://api.gm.ondo.finance/v1/assets/{asset_id}/prices/latest",
    headers={"Authorization": f"Bearer {api_key}"},
)
print(response.json())
```
</CodeGroup>
